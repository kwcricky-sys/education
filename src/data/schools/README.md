# 學校詳情 JSON（請歸位至此）

請將 Hermes / R2 的獨立學校檔案放到本資料夾：

```
src/data/schools/
  1.json
  2.json
  …
  507.json
```

亦相容 R2 命名：

```
src/data/schools/school_1.json
```

同時請放置總表：

```
src/data/schools_summary.json
```

詳情檔建議欄位：`id`, `name_zh`, `name_en`, `school_net`, `finance_type`, `gender`, `address`, `website`, `seo_summary`, `secondary_allocation`, `interview_prep`, `admission_info`。
